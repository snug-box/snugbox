Questions

How much does it cost?

Nothing. Snugbox is free.

What Linux systems does it support?

Use Linux 5.4 or newer with cgroup v2. The watcher and reversible fixes also use systemd. See the installation guide for requirements.

Does it send my audit data anywhere?

Snugbox keeps audit history on the server. The agent can query your provider's local metadata service, and alerts can use a webhook you configure. Read the data policy for details.
